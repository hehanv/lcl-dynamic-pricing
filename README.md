# LCL 유연상품 추천운임

소량화물(LCL) 해상운송에서 화물 치수와 선적 시점을 입력하면 **표준운임과 유연운임을 함께 산출**하는 서비스입니다.
유연운임은 선적 지정 권한을 선사에 위임하는 대신 할인을 받는 상품이며,
할인율 d\*는 강화학습으로 도출한 정책표에서 조회합니다.

## 서비스

| 구분 | 주소 |
|---|---|
| 서비스 화면 | https://lcl-dynamic-pricing.onrender.com/app |
| API 문서 | https://lcl-dynamic-pricing.onrender.com/docs |
| 데모 영상 | (제출 시 기입) |

> API 서버는 무료 플랜으로 운영되어 15분 이상 요청이 없으면 대기 상태로 전환됩니다.
> 이 경우 첫 요청에 최대 1분이 소요될 수 있으며, 화면에 안내가 표시됩니다.

## 문제 정의

LCL은 여러 화주의 화물을 한 컨테이너에 혼재해 운송합니다. 선사는 두 가지를 동시에 마주합니다.

1. **적재 효율** — 남는 공간은 손실이지만, 화물 형상 때문에 부피가 남아도 물리적으로 들어가지 않을 수 있습니다.
2. **판매 시점** — 마감이 가까울수록 빈 공간을 채우는 편이 유리하지만,
   너무 일찍 깎으면 제값 받을 화물까지 할인하게 됩니다.

이 서비스는 **판매 잔여기간 × 잔여 선복**을 상태로 학습된 할인 정책을 조회하고,
실시간 적재 가능 여부를 함께 판정해 운임을 제시합니다.

## 동작 구조

```
[웹 화면 /app]
      │  HTTP
      ▼
[FastAPI server.py]
      ├─ EP 적재 휴리스틱   이 화물이 물리적으로 들어가는가        (lcl_core)
      ├─ 정책 조회          (시점, 잔여선복) → 할인율 d*          (policy_bank)
      └─ 운임 산출          r_S × (1 − d*) × 청구CBM
```

- **청구 CBM** 은 부피와 중량 중 큰 값을 적용합니다 (W/M 룰).
- **시즌** 은 두 컨테이너 각각에 대해 성수기 / 일반기 / 비성수기로 지정합니다.

## 이용 대상별 화면

하나의 계산 엔진을 공유하되 노출 범위만 다릅니다.

| | 운영자용 | 화주용 |
|---|---|---|
| 입력 | 화물 치수·중량, 선적, 마감 잔여일, **잔여 선복, 수요 국면, β, δ_F, 구간운임** | 화물 치수·중량, 선적, 마감 잔여일 |
| 출력 | 할인율 d\*, 표준/유연 운임, 민감도 5종, 정책 요율표 | 표준/유연 운임과 절감액 |

## 파일 구성

| 파일 | 설명 | 구분 |
|---|---|---|
| `server.py` | FastAPI 서버. 견적·민감도·요율표·시황 엔드포인트 | **본선 당일** |
| `static/app.html` | 웹 화면. 의존성 없는 단일 HTML | **본선 당일** |
| `lcl_pricer.py` | 정책 조회 및 운임 산출 엔진 | 선행 연구 |
| `lcl_core.py` | EP 적재 휴리스틱, MNL 선택모형 | 선행 연구 |
| `results/policy_bank.json` | 학습 완료된 통합 정책표 (80 셀) | 선행 연구 산출물 |
| `results/shards/` | β × δ_F × 시즌 조합별 개별 정책 (80개) | 선행 연구 산출물 |
| `results/*.csv` | 축별 학습 결과 요약표 | 선행 연구 산출물 |

> 할인 정책 학습과 적재 휴리스틱은 본선 이전에 수행된 선행 연구 자산입니다.
> 본선 당일 수행한 작업은 **서비스화** 범위입니다 — REST API 설계 및 구현,
> 웹 화면 기획 및 구현, 두 이용대상에 맞춘 인터페이스 분기, 배포.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/app` | 웹 화면 |
| GET | `/meta` | 정책 축, 시즌, 기본값 |
| POST | `/quote` | 표준 / 유연 운임 산출 |
| POST | `/sensitivity` | 민감도 5종 |
| POST | `/ratecard` | 시점 × 잔여선복 요율표 |

## 시황 참고 지표

가격 판단에 필요한 시장 맥락을 함께 제공합니다.

| 기관 | 지표 | 본 서비스와의 연결 |
|---|---|---|
| 한국해양진흥공사 | KCCI 컨테이너선 운임지수 | 부산항 기준 시장 운임 수준 → 구간운임 r_S |
| 국가물류통합정보센터 | 항만별 물동량 | 수요 국면 판단 → 시즌 파라미터 |
| 국가물류통합정보센터 | 선박 입출항 | 선복 공급 압력 → 잔여 선복 해석 |

환경변수 `GEMINI_API_KEY` 를 설정하면 Gemini + Google 검색으로 시황 요약이 함께 생성됩니다.
설정하지 않아도 공식 지표 링크는 항상 표시됩니다.

## 알려진 한계

- δ_F 는 두 점 격자로 학습되어 있어, 화면에서 그 사이 값을 선택하면 최근접 정책이 적용됩니다.
  실제 적용된 값은 결과 상단에 표시됩니다.
- 잔여 선복만 주어진 경우, 해당 잔여를 재현하는 대표 적치를 시드 고정으로 합성해 적재 판정에 사용합니다.
